# ZineROM A115F project page

A bilingual Arabic/English static landing page for the experimental One UI 7 port for Samsung Galaxy A11 (SM-A115F).

- Live build link: [ZineROM One UI 7 A115F test ZIP](https://github.com/nova-arch008/ZineROM-A115F-OneUI7-boot-test/releases/download/a115f-boot-test/ZineROM_OneUI7_A115F-Port-A057F.zip)
- Project repository: [ZineROM-A115F-OneUI7-boot-test](https://github.com/nova-arch008/ZineROM-A115F-OneUI7-boot-test)
- Hosting: GitHub Pages, deployed by `.github/workflows/pages.yml`.

The page clearly labels the ROM as experimental and displays its SHA-256 digest for download verification.
